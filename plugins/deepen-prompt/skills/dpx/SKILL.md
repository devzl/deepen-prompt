# DPX shortcut

Read [Deepen Prompt](../deepen-prompt/SKILL.md) and follow its instructions
for the user's supplied task or question. If no task is supplied, use the
most recent task in the conversation, as the canonical skill specifies.

This is an alias for `deepen-prompt`; do not run a separate rewrite workflow
or invoke this shortcut recursively.
